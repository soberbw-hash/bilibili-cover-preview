# B站封面预览

把自己的视频封面放进近似 B 站首页和手机端推荐流里，快速判断它在一堆竞品封面中够不够醒目、有没有点击欲。

这是一个纯静态的小工具，不需要后端、不需要登录、不需要构建。打开后导入你的封面，就能在网页端首页、手机端双列信息流、深色模式等场景里做第一眼测试。

## 功能

- 网页端首页结构预览：顶部导航、频道区、轮播大图、推荐视频流。
- 手机端推荐流预览：模拟 B 站 App 首页双列卡片样式。
- 内置竞品封面素材池：打开页面后自动加载，不用每次重复导入。
- 导入和拖拽上传：选择图片或把图片拖到任意卡位即可替换。
- 随机封面环境：一键重排周围封面，保留你的封面位置。
- 深色模式：检查封面在浅色/深色界面里的对比度。
- 轮播大图：模拟网页端首页大图的 5 秒自动轮播、圆点和手动切换。
- 一键截图：截取当前预览区域，优先写入剪贴板，失败时自动下载 PNG。
- 赞助作者：内置赞助二维码弹窗。

## 快速开始

macOS 本地推荐双击：

```text
打开预览.command
```

它会自动启动本地静态服务，并打开：

```text
http://127.0.0.1:8765/index.html
```

也可以手动启动：

```bash
python3 -m http.server 8765
```

然后访问：

```text
http://127.0.0.1:8765/index.html
```

不建议直接用 `file://` 打开后截图。Chrome 对本地图片导出 canvas 有安全限制，截图功能会被拦截；用上面的本地服务方式即可正常使用。

## 使用建议

1. 导入你的封面。
2. 多点几次“随机封面”，看它在不同竞品旁边是否仍然醒目。
3. 切换网页端、手机端和深色模式分别检查。
4. 打开“我的封面标记”只用于定位；真正判断点击欲时建议关掉标记。
5. 用“一键截图”把当前效果发给朋友或团队一起看。

## 更新素材库

把新的 JPG 封面放进 `covers/`，再在 `index.html` 的 `competitorCovers` 数组里追加一条记录。

示例：

```js
{
  cover: 'covers/你的封面文件名.jpg',
  title: '参考视频标题',
  owner: '参考UP',
  viewText: '12.3万',
  danmakuText: '88',
  durationText: '08:30',
  sourceName: '其他博主封面'
}
```

后续可以再做一个自动生成素材清单的小脚本，把这一步变成“丢进文件夹就自动识别”。

## 部署

这是纯静态项目，部署到 GitHub Pages、Vercel、Netlify 或任意静态文件服务都可以。入口文件是 `index.html`。
